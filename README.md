# NETFLIX CHECKER 🎬🍿
## What is the project about?
### - The project is about whole Movies and TV Shows added to Netflix's catalog. We can check some information about every titles available on Netflix.
## What kind of data has been analyzed?
### We can find a lot of information about the titles, for example:
- date added to Netflix,
- the cast,
- country/countries where the title was created,
- the genre of each title 
and more :)
## What is the purpose?
### I wanted to answer a few questions:
- What are the most popular genres of titles on Netflix?
- Which year was the most popular year for release new titles?
- Which country produced the most titles?
- Are there more movies or TV Shows?
- What is the longest movie? Is it worth watching? ;)

### After prepared whole outputs, I was surprised by some of the answers. But I don't want to spoil the surprise. If you're curious about what surprised me, feel free to explore the CSV files and discover the answers yourself! ;) 

## Technologies used
- Python - The main programming language used in this project.

- Pandas - Used for data cleaning, transformation, and analysis, including filtering, grouping, sorting, and handling missing values.

- PyCharm - The IDE used to develop and run Python scripts.

- CSV - Used to store the original dataset, cleaned data, and final analysis results.

- GitHub - Used to share and document the project.

## How to Run the Project
1. Download or clone this repository.
2. Make sure Python and pandas are installed.
3. Open the project in PyCharm or another Python IDE.
4. Set the working directory to the project's root folder.
5. Run the scripts in the following order:
   - 01_inspect_dataset.py - Explore the original Netflix dataset.
   - 02_clean_data.py - Clean the dataset and save it as a new CSV file.
   - 03_analyze_data.py - Analyze the cleaned data and generate the results.
6. Explore the generated CSV files in the output files folder.
Dataset: Netflix Movies and TV Shows dataset from Kaggle - https://www.kaggle.com/shivamb/netflix-shows.
